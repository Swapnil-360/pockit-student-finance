# Student Financial Management & Risk Warning System (Mobile App)
### শিক্ষার্থীর অর্থ ব্যবস্থাপনা — মোবাইল অ্যাপ্লিকেশন v2.0

Cross-platform React Native mobile application built with **Expo SDK 58** (`react@19.3.0`, `react-native@0.88.1`, `typescript@~6.0.3`), adhering strictly to the **Mobile App Product Design & Engineering Standard**.

---

### Key Capabilities & Screens

1. **Design System & Ergonomics:**
   - **No Status Bar Overlap:** Platform-aware safe-area padding dynamically handles Android punch-hole cameras, notches, and status bars (`Platform.OS === 'android' ? (StatusBar.currentHeight || 24) + 8 : 44`).
   - **Touch Target Compliance:** All interactive buttons, chips, and steppers have a minimum touch target of 48dp.
   - **Fintech Obsidian Palette:** WCAG AA contrast compliance with clear semantic signals (`riskLow #10B981`, `riskModerate #F59E0B`, `riskHigh #EF4444`).
   - **Bengali Typography Standard:** Generous `lineHeight` scales to prevent Bengali vowel/diacritic clipping. Zero tacky emojis used as interface elements.

2. **App Entry & Security:**
   - **Branded Animated Splash Screen (`SplashScreen.tsx`):** Geometric emblem, branded tagline, and session/PIN check.
   - **4-Digit App Lock PIN / Biometric Screen (`PinLockScreen.tsx`):** Number pad, PIN dots indicator, and Fingerprint / Face ID biometric authentication via `expo-local-authentication`.
   - **Authentication (`AuthScreen.tsx`):** Email & Password Sign In, Sign Up, Forgot Password / Password Reset modal, and 1-Click Instant Demo login.

3. **4-Tab Navigation & Screens:**
   - **1. Home (`HomeScreen.tsx`):**
     - Live 0–100% Risk Gauge with risk tier badge (<40% Low, 40–69% Moderate, >=70% High) and vulnerability alerts.
     - **Safe Daily Spending Limit Card:** Prominent `৳Tk/day` quota calculated across remaining days to prevent month-end debt, with burn-rate status (Healthy / Caution / Critical).
     - **Dual Fast CTAs:** `+ Add Income` (emerald) and `- Add Expense` (cyan).
     - Pro Status / Upgrade banner.
     - 4-tile financial metrics grid (Monthly Allowance, Total Spent, Remaining Balance, Projected Savings).
     - Automatic local push notification alert triggered if risk surges $\ge 70\%$.
   - **2. Calendar & Ledger (`CalendarLedgerScreen.tsx`):**
     - Real-time monthly calendar cycle from 1st to 28th/30th/31st with Month Switcher (`< November 2026 >`).
     - Monthly summary: Total Inflow, Total Outflow, and Net Cashflow.
     - Interactive calendar grid with activity dots (green for income, red for expense). Tapping any date filters transactions to that specific date.
     - Filter tabs (`All`, `Income`, `Expense`), payment method badges (`bKash`, `Cash`, `Nagad`, `Rocket`, `Bank`), notes, and delete action.
   - **3. AI Coach (`AiCoachScreen.tsx`):**
     - **Freemium Gate:** Free users see a Pro preview card with benefit breakdown and 1-click Demo Pro unlock button.
     - **Pro Active:**
       - **Daily Advice Tab:** Today's spending focus, category trim recommendations, and practical Bangladeshi campus hacks (Nilkhet books, canteen dining, sharing rickshaws) generated by **Google Gemini 2.5 Flash**.
       - **"Ask AI Before I Buy" Simulator Tab:** Enter item name, cost, and category before buying to predict the exact shift in Risk Score % and Daily Safe Allowance, receiving an algorithmic verdict (`PROCEED`, `WARN`, `AVOID`) with empathetic Bengali & English guidance.
   - **4. Profile & Settings (`ProfileScreen.tsx`):**
     - Student profile, baseline allowance, and behavioral progress bars (Awareness & Impulse indices).
     - Pro Subscription status tile with Upgrade/Manage action.
     - Security & Privacy tile with 4-Digit PIN configuration and Biometric status.
     - Notifications tile with Daily 9:30 PM reminder push notification toggle.
     - Past Monthly Archives modal with historical balances and risk snapshots.
     - **Month-End Check-In Card:** Ground-truth question ("Did you run out of money?") that serializes into the exact 24-column training schema to feed continuous model learning.

4. **Tactile Modals:**
   - `AddIncomeModal.tsx`: Add funds anytime from multiple sources (`Family`, `Tuition`, `Freelance`, `Scholarship`, `Gift/Other`).
   - `LogExpenseModal.tsx`: Ultra-fast (<5s) expense logging with payment method chips and optional note.
   - `ProSubscriptionModal.tsx`: Tk 50/Month Pro subscription with bKash/Nagad Send Money instructions, TrxID verification, and instant 1-click Demo Pro unlock.
   - `ForgotPasswordModal.tsx`: Student password reset.

### Running the Mobile App

1. **Install Dependencies:**
   ```bash
   cd mobile-app
   npm install
   ```

2. **Verify Project Health:**
   ```bash
   npx expo-doctor
   npx tsc --noEmit
   ```

3. **Start Expo Development Server:**
   ```bash
   npx expo start
   ```
   - Press `w` to run in web browser.
   - Open **Expo Go** on Android / iOS and scan the QR code.
   - **Backend Connectivity:**
     - Android Emulator: Uses `http://10.0.2.2:8000` automatically.
     - iOS Simulator: Uses `http://localhost:8000` automatically.
     - Physical Phone via Expo Go: Ensure phone and PC are on the same Wi-Fi network, and update `DEFAULT_HOST` in `src/services/api.ts` to your PC's local IP (e.g. `http://192.168.1.X:8000`).
